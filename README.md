# Adrobot Campaign Manager

FastAPI-приложение для создания кампаний Keitaro и управления офферами в существующих кампаниях. SQLAlchemy хранит локальную копию созданных приложением данных; редактор читает актуальные кампании и потоки из Keitaro.

## Требования и запуск

Требуется Python 3.11+.

```powershell
# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
Copy-Item .env.example .env
# Заполните .env локально: KEITARO_BASE_URL и KEITARO_API_KEY
alembic upgrade head
uvicorn app.main:app --reload
```

В браузере: http://127.0.0.1:8000 . Swagger UI: http://127.0.0.1:8000/docs . В macOS/Linux активируйте окружение командой `source .venv/bin/activate`; скопируйте конфиг через `cp .env.example .env`.

## Миграции базы

Alembic конфигурируется через `DATABASE_URL` из `.env`.

```bash
alembic upgrade head       # применить миграции
alembic current            # текущая версия схемы
alembic revision --autogenerate -m "описание изменения"
alembic downgrade -1       # откатить одну миграцию
```

Начальная миграция создаёт `campaigns` и `campaign_offers`. Она безопасно пропускает создание таблиц, если они уже существуют в старой SQLite базе приложения.

## Настройка Keitaro

Укажите корневой URL трекера без `/admin_api` и API key в `.env`. Не коммитьте `.env`; он исключён через `.gitignore`. Нужны права API на чтение кампаний, потоков, офферов, доменов, групп и источников, а также создание кампаний/потоков и обновление потоков.

Создатель задаёт название, двухбуквенный код страны, оффер, домен, группу и источник. Создаётся поток Google с фильтром страны и поток офферов. Редактор загружает кампании непосредственно из Keitaro; доли офферов при добавлении/удалении пересчитываются поровну, сумма долей остаётся 100%, последний оффер удалить нельзя.

## Проверка

Создавайте кампании с префиксом `test_<фамилия>_`, как указано в задании. Для первого ручного прогона используйте доступный тестовый оффер и тестовые группу/источник. Запуск создания изменяет Keitaro.
